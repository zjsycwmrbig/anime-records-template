      ONLINE MANAGEMENT

      连接数据仓库

      公开仓库无需 Token 即可浏览。编辑、删除和同步需要 GitHub 细粒度 Token；验证成功后会缓存到当前浏览器本地，之后打开管理页会自动填充。

      Token 权限 仅选择该数据仓库，并授予 Repository permissions → Contents: Read and write。若要通过管理页从模板更新，模板中的 .github/workflows/ 还需要 Workflows: Read and write； 仅编辑番剧数据时不需要该权限。不要使用写入 URL 或提交到仓库的 Token。 创建细粒度 Token
